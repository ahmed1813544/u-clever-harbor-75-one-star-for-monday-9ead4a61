A one-star review of Monday, written as if Monday were a restaurant — one
line, 24 words, 127 characters.

> The waiter cleared my weekend's table before I sat down, then Monday
> served me a week of cold coffee and charged for the alarm.

## Entry

`main.py` (Python 3.13, standard library only) writes that single line to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It is
fully deterministic: no network, no randomness, no timestamps, so both
sandbox runs write the same bytes.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
